# 个性化配置（personalization）

## 这是什么

用户的**全局个性化配置**存放在 DSH 用户目录下的 `AGENTS.md`（即 `$DSH_HOME/AGENTS.md`）。

- 它是 DSH 的**用户全局指令文件**：每个会话开始前都会把它的内容注入工作区指令基线（用户全局层），因此**对所有项目、所有会话生效**。
- 它表达的是**用户的个人偏好**。当它与项目级说明（如仓库根目录的 `AGENTS.md`）冲突时，以本文件（用户全局个性化）为准——这是用户明确的要求。
- 文件内容为 Markdown，UTF-8 无 BOM，总大小建议控制在 64KB 以内（DSH 指令预算），超出会从最具体的文件开始截断。

## 编辑方式

1. **用户可在 GUI 里编辑**：设置 → 插件 → 插件配置 →「个性化」卡片，保存后直接写回本文件。
2. **Agent 直接编辑**：用 `read` 读取当前内容 → 用 `write`/`edit` 修改 → 保持 UTF-8 无 BOM。

## 修改规则

- 编辑时**保留**文件顶部的说明注释（`# 个性化配置（用户全局）` 及引用块），只改「个性化偏好」小节。
- 内容按小节组织，便于用户日后增删：
  - `## 个性化偏好`：用户要求每个会话遵守的通用约束（如默认语言、回复风格、代码注释习惯等）。
  - 用户新增小节时原样保留，不要合并或重排。
- **不要删除整个文件**；文件缺失时用默认模板重新创建（模板见下）。
- 保存后：新会话立即生效；当前会话中由 Agent 用编辑工具写入也会热同步。

## 默认模板（文件缺失时重建）

```markdown
# 个性化配置（用户全局）

> 本文件是用户级全局指令：DSH 会在每个会话开始前把它注入工作区指令基线（用户全局层）。
> 编辑方式：设置 → 插件 → 插件配置 → 个性化，或直接让 Agent 修改本文件。
> 保存后，新会话立即生效；会话中由 Agent 用编辑工具修改也会热同步。

## 个性化偏好

在这里写下你希望每个会话都遵守的通用约束，例如：

- 默认使用简体中文回复；
- 代码注释和提交信息使用简洁中文；
- 改动前先说明影响范围。
```

## 使用时机

- 用户说“个性化”或要求设置全局约束时：先 `read` 当前文件，展示现有内容，询问要新增/修改哪些条目，再写入。
- 用户要求删除某项时：只删除对应条目，保留其余内容。
- 每次修改后向用户确认：已写入 `~/.dsh/AGENTS.md`，新会话生效。
